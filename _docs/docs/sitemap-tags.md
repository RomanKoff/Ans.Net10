# Архитектура подсистемы тегов и динамической фильтрации в Ans.Net10.Web

Подсистема тегов предназначена для декларативного управления видимостью (`show`, `hide`) и структурным поведением (`pass`) элементов навигационного графа (информационных узлов `NodemapItem` и контентных страниц `PagemapItem`). Подсистема оптимизирована для работы в высоконагруженных CMS-платформах и использует подход __Zero-Allocation__ при сопоставлении строк.

## 1. Декларативное описание в конфигурации

Управление тегами поддерживается как на уровне XML-конфигураций (`appsettings.xml`), так и при программных инъекциях через легковесные структуры описания (`NodemapDef` / `PagemapDef`).

__Пример XML-разметки карт:__

```xml
<nodes xmlns="urn:ans:net10:web:map-nodes">
    <!-- Элемент скрыт для всех, кроме пользователей с тегом "premium" -->
    <item target="catalog" face="Каталог товаров" show="premium" />
    
    <!-- Элемент виден всем, кроме пользователей с тегом "archive" -->
    <item target="old-releases" face="Архивные релизы" hide="archive" />
    
    <!-- Сквозной декоративный узел: сам не рендерится, но поднимает детей на уровень выше -->
    <item target="system" face="Служебный раздел" pass="system-mode" />
</nodes>
```

__Пример программной инъекции в `Program.cs`:__

```csharp
await app.Use_AnsNet10WebAsync(sitemap =>
{
    var nodeDef = new NodemapDef(
        target: "_debug", 
        face: "Отладка системы", 
        tagShows: "admin", 
        tagHides: "production"
    );
    sitemap.AddTopNodeDef(nodeDef);
});
```

## 2. Управление памятью и Жизненный цикл (Zero-Allocation)

Для предотвращения дублирования строк и экономии оперативной памяти на уровне базового прототипа `_MapItem_Proto` не хранятся сырые XML-строки. При инициализации элемента навигации текстовые данные парсятся в __nullable-массивы__ строк в нижнем регистре.
Если теги в конфигурации не заданы, свойства принимают значение `null`. Это избавляет приложение от аллокаций пустых массивов (`[]`) в куче для 90% стандартных страниц сайта.

__Атомарный метод разбора тегов:__

• Разделителями тегов выступают символы запятой `,` и точки с запятой `;`.
• Все теги очищаются от пробелов и приводятся к нижнему регистру (`ToLowerInvariant`).
• Дубликаты тегов автоматически исключаются на этапе сборки графа.
• Если строка состоит только из пробелов или разделителей, метод возвращает `null` вместо пустого массива.

## 3. Матрица и алгоритм проверки видимости (`IsDisplayed`)

Метод проверки видимости поддерживает передачу одиночного тега контекста (например, роли текущего пользователя) с поддержкой необязательного `null`-значения для анонимных посетителей:
```csharp
bool IsDisplayed(string? tag = null);
```

__Разрешение конфликтов интересов (Приоритеты):__

При одновременном использовании атрибутов `show` и `hide` для одного элемента, их обработка выполняется по строго детерминированному алгоритму:
1. Белый список (`show`) — Высший приоритет:
Если у элемента задан `ShowsArray`, система проверяет совпадение. Если тег контекста пуст или не совпадает с белым списком, метод __мгновенно возвращает__ `false`, полностью игнорируя черный список.
2. Черный список (`hide`) — Второй приоритет:
Если элемент прошел проверку белого списка (или он не задан), система сверяет тег с `HidesArray`. При совпадении с черным списком метод возвращает `false`.
3. Общий доступ (Fallback) — Третий приоритет:
Элемент успешно отображается (`true`), если он удовлетворяет белому списку и не заблокирован черным списком.

__Логика обработки анонимных пользователей (`tag = null` или пустой):__

Если тег контекста не передан, элемент отображается только в том случае, если для него __не заданы ограничения белого списка__ (`ShowsArray is null`). Наличие черного списка в данном сценарии роли не играет.

## 4. Групповые операции и Сквозной проход (`Passthrough`)

Для удобства интеграции с современными контекстами авторизации (например, __Keycloak__, где у пользователя всегда присутствует массив ролей) подсистема предоставляет оптимизированные перегрузки, работающие с коллекциями строк или сырыми строками тегов, разделенными запятыми:
• `IsDisplayedTags(IEnumerable<string>? activeTags)` — возвращает `true`, если совпал хотя бы один разрешенный тег.
• `IsDisplayedTags(string? rawActiveTags)` — автоматически парсит контекстную строку на лету и вычисляет видимость.

__Сквозной проход (`IsPassthroughTags`):__

Используется для прозрачных элементов меню. Логика прозрачности является закрытой: если тег контекста пуст или равен `null`, метод всегда возвращает `false`, и элемент обрабатывается как стандартный физический узел. Сквозное поведение активируется только при явном совпадении тега из `PassthroughsArray`.
